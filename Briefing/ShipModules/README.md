# Ship Modules

35+ mothership modules categorized by function: drives, storage, protection, scanning, weapons, labs, and support.

---

## Module System Overview

### Grid Placement

- Modules occupy grid slots on the mothership hull (2D top-down view of ship layout)
- Minimum starting size: Cockpit (1x1) + Engine bay (1x1) + Habitation (1x1) + Drop module (2x2) + Storage (1x1) + Energy core (1x1) = 8 base slots
- Modules can be expanded by adding new hull sections (costs construction material + minerals)
- Module improvements: 10x improvement cycle gives escalating bonuses (5%, 12%, 20%, 30%, etc.)

### Module Categories

| Category | Starting | Expandable | Notes |
|----------|----------|------------|-------|
| Drives | 1 (Rocket) | Up to 4 slots | Determines travel speed and range |
| Storage | 1 (Locker) | Up to 8 slots | Resource capacity per type |
| Protection | 1 (Basic Hull) | Up to 3 slots | Ship HP and environmental resistance |
| Scanning | None | Up to 4 slots | Radar, sonar, satellite systems |
| Weapons | None | Up to 4 slots | Turrets, bays, emitters |
| Labs/Research | None | Up to 3 slots | Research facilities, crafting |
| Support | 1 (Habitation) | Up to 6 slots | Crew capacity, med bay, hangars |
