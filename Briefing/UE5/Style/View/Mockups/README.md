# Stil-1 Game View Mockups

These 16:9 concept plates establish the visual direction for the major game views before final UI and asset production. They follow `UI_THEME.md`: dark gunmetal panels, chamfered military geometry, orange primary actions, blue interaction and information states, green positive status, red danger, and purple elite technology.

| File | View | Primary purpose |
|---|---|---|
| `01-Game-Welcome-Screen.png` | Welcome / main menu | Campaign entry and settings navigation |
| `02-Dropship-Crash-Sideview.png` | Crash cinematic | Side-view tutorial opening and impact prompt |
| `03-RTS-Base-View.png` | Planet RTS view | Standard base management HUD |
| `04-RTS-Construction-Mode.png` | Construction mode | Building selection, cost, rotation, and grid placement |
| `05-Tactical-Combat-Dungeon-View.png` | Combat / dungeon view | Squad control, abilities, objectives, and room exploration |
| `06-Dropship-Repair-View.png` | Dropship systems | Ship repair, salvage, and module installation |
| `07-Research-Tech-Tree.png` | Research network | Radial TIR progression and technology requirements |
| `08-Colony-Resource-Network.png` | Colony network | Production, logistics, workers, storage, and transfers |
| `09-Solar-System-UI.png` | Solar-system map | Planet scanning, route planning, and landing preparation |
| `10-Galaxy-System-UI.png` | Galaxy map | Ring progression, wormholes, threats, and multi-hop travel |
| `11-Space-Combat-View.png` | Space encounter | Ship combat, targeting, weapons, and encounter choices |
| `12-Inventory-Equipment-View.png` | Inventory / equipment | Squad loadouts, blueprints, stats, and quick slots |

## Production notes

- Treat these as layout and art-direction references, not final pixel-perfect UMG screens.
- Rebuild typography and icons natively in Unreal for consistent scaling and localization.
- Keep the central gameplay area clear; panels should be collapsible where practical.
- Use the exact palette and widget rules from `UI_THEME.md`.
- Validate final layouts at 1920×1080, 2560×1440, 3440×1440, and Steam Deck resolutions.
