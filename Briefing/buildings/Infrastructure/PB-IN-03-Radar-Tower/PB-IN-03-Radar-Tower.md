# Radar Tower (PB-IN-03)

**Tier:** Default (TIR 1-2)
**Category:** Resource Extraction

## Specs
- **Grid Size:** 1x1 (tall structure)
- **Cost:** 150 construction material, 200 minerals
- **Power:** Requires 20 energy/turn
- **Function:** Discovers area, increases scanning range
- **Range:** Base 2x fuel range [See navigation](../../../Planets/Navigation/README.md)

## Notes
Upgrades with TIR tier. Each TIR level adds +50% scan range. Essential for dungeon discovery
