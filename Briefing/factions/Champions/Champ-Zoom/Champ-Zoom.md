# Zoom

**Role:** Pip Tanaka

## Abilities
- **Dash (Lvl 5):** Instant dash forward 15m, leaves afterimage that confuses enemies for 3 seconds
- **Rocket Boots (Lvl 10):** Jetpack flight for 20 seconds, can hover and strafe
- **Slam Attack (Lvl 20):** Leap to target location, dealing area damage and knocking back enemies

## Passive
+30% movement speed for all units, reduced detection range for base
