# Resource 5: Hull

### Purpose
Specialized material for ship armor plating and heat resistance. Required for dropship repair, hull reinforcement, and shield generation systems.

[Back to Resources Overview](../README.md)

---

### Hull Material Types and Sources

| Hull Material Type | Heat Resistance Rating | Source Biome | Processing Required | Application |
|-------------------|----------------------|--------------|-------------------|-------------|
| Standard Steel | Baseline (1x) | All biomes (scavenged) | Basic smelter | Initial dropship hull repair |
| Titanium Alloy | +200% thermal resistance | Rocky, Ice | Titanium smelter + alloy forge | TIR 2-3 hull reinforcement |
| Advanced Heat-Shield Alloy | +400% thermal resistance | Crystal Caves, center galaxy | Advanced alloy forge | TIR 4-5 hull reinforcement |
| Alien Composite Shield | Immune to physical damage | Center galaxy ruins | Alien artifact decoder | Post-endgame [See Dropship](../../Spaceship/Dropship/README.md) |

### Hull Material Output Values

| Source | Output per Cycle | Time per Cycle | Energy Cost | Rarity |
|--------|-----------------|----------------|-------------|--------|
| Scavenged from crash site | 25 hull parts | None (instant) | None | Starting inventory |
| Standard mine (steel deposits) | 10 hull/cycle | 5 minutes | None | Common |
| Titanium mine | 4 hull/cycle | 8 minutes | None | Rare |
| Dungeon loot (military bases) | 50-300 hull parts | Varies by dungeon size | None | Uncommon-Rare |
