# Resource 4: Minerals

### Purpose
Advanced crafting material for equipment upgrades, weapon production, and high-tier building components. Different mineral types unlock different crafting recipes.

[Back to Resources Overview](../README.md)

---

### Mineral Types and Sources

| Mineral Type | Color Indicator (Smoke from Mine) | Source Biome | Processing Required | Use Case |
|-------------|----------------------------------|--------------|-------------------|----------|
| Glass | Clear/transparent | Desert, Rocky | Sand furnace | Basic crafting, optics |
| Crystal | Green glow | Crystal Caves, Ice | Crystal synthesizer | Energy weapons, TIR 3+ research |
| Sulfur | Yellow smoke | Desert, Rocky | Sulfur extractor | Explosives, chemical processing |
| Uranium (Radioactive) | Green radioactive glow | Rocky, Crystal Caves | Uranium refinery | Atomic reactors, advanced weapons |
| Titanium | Silver-blue sheen | Rocky, Ice | Titanium smelter | Hull plating, armor upgrades |
| Advanced Alloys | Multi-color shimmer | Dungeon loot, center galaxy | Alloy forge | TIR 4-5 ship hull reinforcement |

### Mineral Output Values (per source type)

| Source | Output per Cycle | Time per Cycle | Energy Cost | Rarity |
|--------|-----------------|----------------|-------------|--------|
| Basic mineral mine | 10 minerals/cycle | 5 minutes | None | Common |
| Crystal deposit mine | 5 crystals/cycle | 8 minutes | None | Uncommon |
| Sulfur deposit mine | 12 sulfur/cycle | 4 minutes | None | Common |
| Uranium deposit mine | 3 uranium/cycle | 10 minutes | None | Uncommon |
| Titanium deposit mine | 4 titanium/cycle | 8 minutes | None | Rare |
| Dungeon loot (random) | 20-200 minerals | Varies by dungeon size | None | Varies |
