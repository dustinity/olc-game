# Resource 6: Survival (Food + Oxygen Combined)

### Purpose
Unit sustenance resource combining both food and oxygen into a single tracking metric. Prevents unnecessary resource complexity while maintaining survival gameplay tension. Each unit consumes 1 Survival per turn.

[Back to Resources Overview](../README.md)

---

### Survival Source Methods by Biome

| Source Type | Output per Cycle | Biome Availability | Energy Cost | Notes |
|-------------|-----------------|-------------------|-------------|-------|
| Apple trees / Orchards | 15 survival/cycle | Jungle, Water, Swamp | None | Requires planted orchard building |
| Animal hunting | 10 survival/cycle | Jungle, Light Snow, Rocky | None | Requires weapon and trained hunter unit |
| Fishing (Water biome) | 20 survival/cycle | Water only | None | Most efficient natural source |
| Atmospheric oxygen extractor | 30 survival/cycle | All biomes | 15 energy/turn | Extracts breathable O2 from atmosphere |
| Hydroponic farm | 25 survival/cycle | All biomes (indoors) | 20 energy/turn | Controlled environment, reliable output |
| Algae cultivation | 12 survival/cycle | Water, Swamp | None | Low-tech solution for early game |

### Survival Consumption Rates

| Unit Type | Consumption per Turn | Notes |
|-----------|---------------------|-------|
| Infantry soldier | 1 survival/turn | Standard ration |
| Vehicle crew (per person) | 1 survival/turn | Shared within vehicle |
| Champion (player character) | 1 survival/turn | Always active |
| Cryo-stasis soldier | 0.1 survival/turn | Minimal sustenance while frozen |

### Survival Storage and Spoilage

| Storage Type | Capacity | Spoilage Rate | Notes |
|--------------|----------|--------------|-------|
| Dropship storage [See Dropship](../../Spaceship/Dropship/README.md) | 40 starting units | 1% per turn | Refrigerated compartment slows spoilage |
