# Units

Military forces deployed on planet surfaces — infantry, vehicles, aerial units, and support roles.

---

## Overview

Units can be:
- **Trained** at Barracks or Factory buildings
- **Upgraded** through the TIR-based improvement system
- **Equipped** with swappable gear (weapons, armor, utility)
- **Stored** in ship hangars when not in use
- **Controlled** by champions or Command Center
